# 基地分析圖產生器（Site Analysis Generator）

單一 HTML 檔、純前端、可離線使用。上傳基地圖 → 設定比例尺與北向 → 在圖上標記 → 一鍵生成 11 張風格統一的基地分析圖（每張都有標題、圖例、指北針、比例尺和自動產生的「分析結論」）。

## 開啟方式
直接用 Chrome／Edge／Firefox 打開 `site-analysis.html`，不需要伺服器或網路。
想先看看效果，可以按「載入範例基地」（程式產生的虛構街區），再按「▶ 生成分析圖」。

## 使用步驟
1. **專案與基地圖**：上傳地圖截圖、地籍圖或配置圖（PNG/JPG；長邊超過 1800 px 會自動縮小）。
2. **比例尺・北向・位置**
   - 「📏 兩點量比例尺」：點圖上已知長度的兩端（例如比例尺條、路寬），再輸入實際公尺數；也可以直接填「公尺/像素」。
   - 北向角度＝圖面正上方順時針轉到真北的角度（正北朝上的地圖填 0），也可以用「🧭 兩點設北向」先點南端、再點北端。
   - 緯度、經度、時區預設為台北（25.03°N、121.56°E、UTC+8）。
3. **標記元素**（線、面逐點點擊，按 Enter／雙擊／「完成形狀」結束；Esc 取消；Ctrl+Z 復原；「✖ 刪除」模式下點元素即可刪除）
   - 基地範圍、道路（主要幹道／次要道路／巷道、路寬、單行）、人行動線、車行／人行出入口
   - 建築物（樓層數，用來算陰影與圖底關係）、噪音源（dB）、好景觀／不良景觀
   - 周邊設施（捷運、公車、學校、公園、商業、醫療、機關、文化、停車…）、使用分區、綠地、水體、高程點
4. **分析參數**：日照日期與時間、基地假設量體高度、風向資料來源（預設值或自行輸入，可貼 16 方位風花頻率）、道路噪音參考值、視野錐角、等高線間距、圖底關係模式、SWOT 文字（可按「自動建議」）。
5. **生成與匯出**：勾選要產生的圖 →「▶ 生成分析圖」。每張可以單獨「下載 PNG」，也可以「全部匯出 (ZIP)」（含整張圖版）或「匯出整張圖版」。
   「儲存專案 (.json)」會連同底圖一起存檔，下次載入後可以接著改。

## 產生的分析圖
| # | 分析圖 | 內容 | 需要的標記 |
|---|---|---|---|
| 01 | 基地位置圖 | 基地範圍、面積（m²／坪） | 基地範圍 |
| 02 | 日照分析・太陽軌跡 | 夏至、春秋分、冬至與指定日的太陽軌跡（整點標記）、日出日落方位、指定時刻的太陽高度角和方位角、建築與基地量體陰影（另疊 09/12/15 時） | 建築物（含樓層）、基地 |
| 03 | 風向・季風分析 | 冬／夏季盛行風場、迎風面、背風區、風花圖 | 基地（風向在參數設定） |
| 04 | 動線・交通可及性 | 道路分級與行車方向、人行動線、出入口、捷運／公車站與步行距離 | 道路、出入口、人行動線、運輸站點 |
| 05 | 噪音分析 | 道路線音源加上點音源的 dB(A) 分級色帶，以及基地內最高、最低、平均值 | 道路、噪音源 |
| 06 | 景觀視野 | 好景觀視野錐、不良景觀遮蔽、被看見方向 | 好／不良景觀點 |
| 07 | 周邊機能・土地使用 | 使用分區著色、設施點、400 m／800 m 步行圈與各類設施數量 | 設施、使用分區 |
| 08 | 圖底關係 | 建築為黑、開放空間為白，並算出覆蓋率；沒有畫建築時可依底圖亮度自動判斷 | 建築物（或用影像模式） |
| 09 | 綠地・水系 | 綠地、水體、最近距離與建議的綠色／藍色連結 | 綠地、水體 |
| 10 | 地形・高程 | IDW 內插高程色階、等高線、坡向（逕流）箭頭、基地內高差與坡度 | 至少 3 個高程點 |
| 11 | 綜合分析・SWOT | 疊合主要因子（風、冬至太陽、噪音側、景觀面、出入口）和 SWOT 四格 | 上述資料 |

## 計算方法與資料來源
- **太陽位置**：NOAA 太陽位置演算法（依 Jean Meeus《Astronomical Algorithms》），依輸入的經緯度、日期、時間即時計算高度角與方位角，並做大氣折射修正。
  驗證（台北 25.03°N、121.56°E）：2026/6/21 日出 05:05、日落 18:46、正午最高 88.4°；2026/12/21 日出 06:34、日落 17:09、正午最高 41.5°，與一般公布的台北日出日落時間相符（差距在 1–2 分鐘內）。
- **陰影**：陰影長度＝高度 ÷ tan(太陽高度角)，投向太陽方位的反方向；建物高度＝樓層 × 每層樓高（預設 3.3 m）。
- **風向預設值**（只是預設，可以自行修改）：
  - 「台灣季風一般風向」：冬季東北季風、夏季西南季風。出處：中央氣象署數位科普網〈隨季節變換的風—季風〉https://pweb.cwa.gov.tw/PopularScience/wt/wt_3.html
  - 「台北盆地」：冬季北部以東北風為主（TCCIP 臺灣氣候變遷推估資訊與調適知識平台 https://tccip.ncdr.nat.gov.tw/km_newsletter_one.aspx?nid=20260326145824 ）；夏季盆地內多數測站以東～東北東風為主（〈台北盆地的夏季風紋與溫度分佈初探〉，2011–2020 年 28 個測站統計，https://doi.org/10.31235/osf.io/xa8wj ）。
  - 要做精確的風花圖，請到中央氣象署 CODiS 下載最近測站的 16 方位風向頻率，貼到參數欄。
- **噪音**：道路視為線音源（距離加倍衰減 3 dB），噪音點視為點音源（距離加倍衰減 6 dB），再做能量加總。道路參考值（主要 75／次要 68／巷道 60 dB(A)，距 10 m）只是示意值，可以修改。
- **地形**：反距離權重（IDW）內插加上 marching squares 等高線。

## 已知限制
- 底圖沒有地理座標，比例尺與北向都要手動設定；沒設定比例尺時暫用 0.5 m/px，圖上會標示「僅供示意」。
- 陰影只考慮平屋頂的稜柱量體，不算地形高差和斜屋頂；建物要手動描繪（沒有自動辨識建物輪廓）。
- 風場箭頭是示意圖，沒有模擬建物繞流或峽谷效應（不是 CFD）；預設風向是一般性描述，不是單一測站的統計值。
- 噪音沒有計入建物遮蔽、反射、地面吸收和車流量，只適合概念階段。
- 景觀視野錐沒有計算遮擋。
- 「自動結論」與「SWOT 自動建議」是依標記資料套用規則產生的草稿，請依設計判斷修改。
- 圖底關係的影像模式依亮度門檻判斷，彩色地圖的道路、綠地可能誤判，請調整門檻或改畫建物。

## v2 視覺強化版（目前的 site-analysis.html）

舊版保留為 `site-analysis-v1.html` 方便比較。v2 仍是單一離線 HTML，所有計算（太陽位置、陰影、噪音衰減、等高線）與資料來源標註不變，只重做了出圖表現：

- **步驟 5 新增「圖面風格」**：淡雅灰白極簡（minimal）、暖色紙質手繪（paper，含紙紋顆粒與手繪斜線）、深色夜間（night）、藍圖（blueprint）。
- **步驟 5 新增「輸出解析度」**：1x / 2x（預設，3840 px 寬）/ 3x。
- 底圖去飽和＋半透明、陰影以 multiply 柔邊混合、噪音以連續色階熱區＋等值線、風場流線繞過基地、漸層彎曲箭頭與光暈、膠囊標籤、圖釘光暈、暈影與裁切標記。
- 每張圖版：大編號＋中英標題、SHEET 編號、圖例卡、說明卡、「KEY FINDING」結論卡、指北與比例尺。
- 「整張圖版」改為競圖風格：大標題、專案指標列（面積、冬/夏至太陽高度角、最近大眾運輸、400 m 內設施數、平均噪音）、三欄卡片排版。

範例輸出：`examples/v2/{minimal,paper,night,blueprint}_NN_*.png` 與 `{theme}_00_board.jpg`。
重產範例：`tests/v2_render.mjs`（需 Playwright；原放在 /workspace/pwtest 下執行）。

v2 限制：效果是程式化產生，非手工 PS 修圖；流線、噪音為示意；未內嵌字型（依系統字型，各電腦外觀略有差異）；2x PNG 約 3–6 MB（paper 因紙紋較大），2x 產圖約 15–25 秒；密集地圖仍可能有標籤靠近。

## v3：輸入 Google 地圖座標自動產生（目前的 site-analysis.html）

v2 備份為 `site-analysis-v2.html`，v1 為 `site-analysis-v1.html`。

### 使用步驟
1. 在 Google 地圖上對基地按右鍵 → 點第一行座標（自動複製），或複製網址列的網址。
2. 打開 `site-analysis.html`，在左側「0 輸入 Google 地圖座標自動產生」貼上，可接受：
   - `25.0330, 121.5654`（十進位）
   - `25°01'58.8"N 121°33'55.4"E`（度分秒）
   - Google 地圖網址：含 `@緯度,經度,縮放z` 或 `!3d緯度!4d經度`（有後者時優先，代表地點標記本身）
   - 短網址 `maps.app.goo.gl/…` 不含座標，需先在瀏覽器開啟後複製完整網址。
3. 選範圍半徑（150／250／400／800 m）、底圖、要匯入的 OSM 圖層，按「📍 依座標產生底圖並匯入」。
4. 程式會自動：
   - 下載底圖瓦片拼成 1600×1200 底圖，依 Web Mercator 計算比例尺（m/px，已含 cos 緯度修正），北向設 0°，經緯度與時區填入日照計算。
   - 用 Overpass API 抓 OpenStreetMap 資料，轉成工具圖層：建築（`building:levels` → 樓層；只有 `height` 時以 高度÷每層樓高；都缺時用預設樓層並標示「估計」）、道路（motorway/trunk/primary → 主要幹道；secondary/tertiary → 次要道路；residential/unclassified/living_street/service → 巷道，同名路段自動接續）、人行步道、綠地公園、水體（河道線依寬度轉面）、土地使用（OSM landuse 推估）、周邊設施（捷運/火車站、公車站、學校、醫療、超商/超市/商場、公園、機關、文化/宗教、停車場）。
   - 高程：Open-Meteo 的 Copernicus DEM GLO-90 取樣 10×8 格點，地形圖改用雙線性內插。
   - 噪音：依匯入道路等級自動推算（有限長度線音源）。
   - 景觀：自動把最大的綠地、水岸及 20 層以上地標設為景觀點。
   - 基地：座標若落在 OSM 建築內，自動以該建築輪廓為基地，並列出其他可選的建築／地塊；否則在座標處放一個預設矩形（寬×深可設）。可勾選「基地內既有建築視為拆除」。
5. 匯入後一切照舊可編輯：「刪除」、「✎ 編輯屬性」（改樓層、道路等級、名稱、設施類型…）、重畫基地範圍。
6. 到步驟 5 選風格、按「生成分析圖」與匯出。

### 圖資與版權
- Google 地圖瓦片需 API 金鑰，且服務條款不允許下載／離線使用，因此不使用。
- 底圖選項：Esri World Topo Map（預設，淡色）、Esri World Street Map、Esri World Imagery（衛星）、OpenStreetMap 標準圖。CARTO 底圖目前回傳「API KEY REQUIRED」，已移除。
- 每張圖右下角與整張圖版的頁尾都會自動印出版權標示：底圖（Esri 服務提供的 copyrightText）、`© OpenStreetMap contributors (ODbL)`、`Copernicus DEM GLO-90 via Open-Meteo`。
- 所有來源都有 `Access-Control-Allow-Origin: *`，以 `crossOrigin="anonymous"` 載入，從 file:// 開啟時 canvas 也不會被污染，可正常匯出 PNG／ZIP。

### 需要網路的部分
只有步驟 0 需要網路；其餘功能（上傳圖、標記、生成、匯出）仍可離線。下載失敗時會顯示繁中錯誤：底圖瓦片失敗、Overpass 伺服器忙碌或逾時（會依序嘗試 4 個公用伺服器、各 2 輪）、高程失敗等，底圖成功但 OSM 失敗時仍保留底圖讓你手動標記。

### v3 限制
- OSM 資料完整度因地而異：缺的建築不會出現在圖底關係與陰影中；約一半建築缺樓層資料（以預設值估計，圖上會註明）。
- 「土地使用」是 OSM landuse 推估，不是法定都市計畫分區。
- Copernicus GLO-90 為 90 m 數值表面模型（含部分建物／植被），市區地形圖僅供大尺度參考。
- 公用 Overpass 伺服器常忙碌，匯入可能要 30 秒～數分鐘，偶爾需要再按一次；800 m 半徑資料量大，較慢。
- 比例尺以座標所在緯度計算；800 m 半徑範圍內 Mercator 比例變化 < 0.1%，可忽略。
- 底圖使用 Esri／OSM 公開服務，請遵守其使用條款（非大量、需標示來源）。
